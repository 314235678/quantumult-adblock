# ===================== 红果短剧 / 番茄系（字节短剧·小说） =====================
# 背景（2026-11 实测）：本清单对红果的覆盖原本是 0 —— youlishipin / fqnovel /
# hongguoduanju 一条规则都没有，所以红果的开屏和中插广告一直拦不住。
#
# ⚠️ 网上流传的「红果去广告 Loon 插件」里有一批域名是虚构的，AliDNS 实测 NXDOMAIN：
#      hongguoapp.com / hongguosdk.com / ad.pangle.cn / hongguo.douyin.com
#    这类规则装上去看着像生效，实际一条都不起作用。而且它还有两条更危险的：
#    DOMAIN-SUFFIX,zijieapi.com（字节通用 API）和 DOMAIN-SUFFIX,bytedance.com
#    （整个字节域），照抄会打穿一堆 App —— 跟京东那次「整域封禁」是同一类错误。
#
# 下面只收两类：① DoH 验证真实解析；② 语义上明确是广告素材或埋点上报。
#
# 广告素材签名 CDN：开屏、中插、悬浮贴片的广告图与素材都从这里出。
